# ToolKit SaaS

A modern, all-in-one online tools platform built with Next.js 14.

## Features

- **PDF Tools**: Merge, split, compress PDFs
- **AI Humanizer**: Transform AI text into natural writing
- **QR Generator**: Create QR codes
- **Image Compressor**: Reduce image file sizes

## Getting Started

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push to GitHub
2. Import to Vercel
3. Deploy!
